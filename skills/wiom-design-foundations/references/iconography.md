# Wiom Iconography System

The approved icon foundation for the Wiom customer app (Android/Kotlin/Compose).
**4 size tokens · 6 icon categories · Material Symbols Rounded · Fill behavior defined**

---

## The 4 Approved Size Tokens

These are the ONLY icon size tokens allowed in new code. No exceptions.

| Token | Glyph | Container | Touch Target | Kotlin | Usage |
|-------|-------|-----------|-------------|--------|-------|
| `icon.xs` | 16dp | 24dp | 40dp | `WiomIcon.XS` | **Restricted:** inline text indicators, input trailing icons, status dots only |
| `icon.sm` | 20dp | 32dp | 40dp | `WiomIcon.SM` | Button icons, compact controls, small trailing actions, dense UI elements |
| `icon.md` | 24dp | 40dp | 48dp | `WiomIcon.MD` | **Default.** Toolbar actions, list icons, nav items, chips, card actions, tabs |
| `icon.lg` | 48dp | 56dp | 56dp | `WiomIcon.LG` | Empty states, onboarding illustrations, hero feature icons, status pages |

### The Scale

```
16(restricted) → 20(compact) → 24(default) → 48(hero)
```

### Glyph vs Container vs Touch Target

These are three separate things. Never confuse them:

- **Glyph** = the visible icon. Set via `WiomIcon.XS / .SM / .MD / .LG`
- **Container** = the visual frame the icon sits in. Includes padding around glyph.
- **Touch target** = the minimum tappable area. Always ≥ container. Invisible to user.

`WiomIconButton` handles container and touch target automatically. You only set the glyph size.

## Icon Source: Material Symbols Rounded

Wiom uses **Material Symbols Rounded** as the only icon library. This applies to every screen, component, and design Claude generates.

- Compose: `painterResource(R.drawable.rounded_<icon_name>)`
- XML: `@drawable/rounded_<icon_name>` vector drawables
- **NEVER create, draw, or generate custom icon SVGs/vectors.** Always use Material Symbols Rounded icons.
- **NEVER use** `Icons.Default.*` (this is Filled, not Rounded)
- **NEVER use** `Icons.Filled.*`, `Icons.Outlined.*`, `Icons.Sharp.*`, `Icons.TwoTone.*`
- **NEVER mix** styles — Rounded is the only approved style for Material icons

### When Material Symbols doesn't have the icon you need

If the design or Figma reference shows an icon that does not exist in Material Symbols Rounded:

1. **Do NOT create a custom icon, SVG, or vector drawable yourself.**
2. **Ask the user** to provide the drawable: *"This icon is not available in Material Symbols Rounded. Please provide the drawable file (ic_wiom_* or ic_partner_*) and I'll integrate it."*
3. Use a **placeholder** comment in code until the drawable is provided:
```kotlin
// TODO: Custom drawable needed — [describe icon] not in Material Symbols
// Ask design team for: ic_wiom_<name>.xml or ic_partner_<name>.xml
Icon(
    painter = painterResource(R.drawable.rounded_help), // placeholder
    contentDescription = "...",
    modifier = Modifier.size(WiomIcon.MD),
)
```
4. Brand icons (`ic_wiom_*`) and partner icons (`ic_partner_*`) are **always** provided by the design team — never generated by Claude.

## 6 Icon Categories

Each category has different fill and color rules. Always identify the category before choosing fill state.

| Category | Examples | Default State | Selected / Active State | Color |
|----------|----------|--------------|------------------------|-------|
| **Action** | back, search, share, close, edit, more, menu | Rounded **filled** | N/A — no selected state | `onSurface` or `onSurfaceVariant` |
| **Navigation** | home, wallet, account, explore, recharge | Rounded outlined (unselected) | Rounded **filled** (selected) | `onSurfaceVariant` unselected, `primary` selected |
| **Status** | success ✓, error ✗, warning ⚠, info ℹ | Rounded **filled** always | N/A | Semantic: `success`, `error`, `warning`, `info` |
| **Toggle** | bookmark, favorite, like, pin, notifications | Rounded outlined (off) | Rounded **filled** (on) | `onSurfaceVariant` off, `primary` on |
| **Brand** | Wiom logo, Wiom SIM icon | Original brand colors | N/A | Brand colors — exempt from tinting |
| **Partner** | WhatsApp, Instagram, YouTube logos | Original brand colors | N/A | Brand colors — exempt from Rounded style |

## Fill Behavior Rules

Filled is the default. Outlined is only used for the inactive/unselected state of interactive toggles.

| Context | Fill Rule |
|---------|----------|
| Toolbar actions | **Filled.** Back, search, share, more — all filled. |
| List / card icons | **Filled.** Leading icons, trailing chevrons, overflow — all filled. |
| Buttons with leading icon | **Filled.** Matches button visual weight. |
| Status / feedback icons | **Filled always.** Success, error, warning, info. |
| Empty states / hero (48dp) | **Filled.** Provides visual presence at large size. |
| Bottom nav / tabs | Outlined when unselected → **filled when selected.** |
| Toggle actions (bookmark, favorite, like) | Outlined when off → **filled when on.** Rare in Wiom. |

**If an icon has no toggle state — it's filled. Outlined is only for the "off" / "unselected" side of a state transition.**

## Token Selection Framework

When writing or reviewing code, ask: **"What is this icon's job on the screen?"**

```
Is it inline with text or inside an input field?       → icon.xs  (16dp) ⚠ restricted
Is it a button icon or compact control?                → icon.sm  (20dp)
Is it a toolbar/nav/list/chip/card action?             → icon.md  (24dp) ← DEFAULT
Is it a hero/empty-state/onboarding/status page?       → icon.lg  (48dp)
Is it a brand mark or partner logo?                    → Custom drawable (ic_wiom_* or ic_partner_*)
```

## Kotlin / Compose Implementation

### Icon Size Object

```kotlin
package com.wiom.ui.theme

import androidx.compose.ui.unit.Dp
import androidx.compose.ui.unit.dp

object WiomIcon {
    /** 16dp — RESTRICTED. Inline indicators, input trailing only. */
    val XS: Dp = 16.dp

    /** 20dp — Button icons, compact controls, dense UI. */
    val SM: Dp = 20.dp

    /** 24dp — DEFAULT. Toolbar, nav, list, chips, cards. */
    val MD: Dp = 24.dp

    /** 48dp — Hero / large. Empty states, onboarding, status pages. */
    val LG: Dp = 48.dp

    // ── Touch Targets ─────────────────────────
    val TouchTargetCompact: Dp = 40.dp   // for XS and SM icons
    val TouchTargetDefault: Dp = 48.dp   // for MD icons
    val TouchTargetLarge: Dp = 56.dp     // for LG icons

    fun touchTargetFor(iconSize: Dp): Dp = when {
        iconSize <= SM -> TouchTargetCompact  // 40dp
        iconSize <= MD -> TouchTargetDefault  // 48dp
        else           -> TouchTargetLarge    // 56dp
    }
}
```

### Usage in Compose

```kotlin
// ✅ Correct — action icon, filled, default size
Icon(
    painter = painterResource(R.drawable.rounded_arrow_back_filled),
    contentDescription = "Back",
    modifier = Modifier.size(WiomIcon.MD),
)

// ✅ Correct — button leading icon, compact size
Icon(
    painter = painterResource(R.drawable.rounded_add_filled),
    contentDescription = null,
    modifier = Modifier.size(WiomIcon.SM),
)

// ✅ Correct — nav icon, filled when selected
Icon(
    painter = painterResource(
        if (isSelected) R.drawable.rounded_home_filled
        else R.drawable.rounded_home
    ),
    contentDescription = "Home",
    modifier = Modifier.size(WiomIcon.MD),
    tint = if (isSelected) MaterialTheme.colorScheme.primary
           else MaterialTheme.colorScheme.onSurfaceVariant,
)

// ✅ Correct — status icon, always filled
Icon(
    painter = painterResource(R.drawable.rounded_check_circle_filled),
    contentDescription = "Success",
    modifier = Modifier.size(WiomIcon.MD),
    tint = MaterialTheme.colorScheme.success,
)

// ✅ Correct — hero icon, filled at 48dp
Icon(
    painter = painterResource(R.drawable.rounded_wifi_off_filled),
    contentDescription = null, // decorative
    modifier = Modifier.size(WiomIcon.LG),
    tint = MaterialTheme.colorScheme.onSurfaceVariant,
)

// ✅ Correct — interactive icon with auto touch target
WiomIconButton(
    icon = painterResource(R.drawable.rounded_search),
    contentDescription = "Search",
    onClick = { /* ... */ },
    iconSize = WiomIcon.MD,
)

// ✅ Correct — partner icon, original colors
Icon(
    painter = painterResource(R.drawable.ic_partner_whatsapp),
    contentDescription = "Share on WhatsApp",
    modifier = Modifier.size(WiomIcon.MD),
    tint = Color.Unspecified, // brand colors preserved
)

// ❌ NEVER — hardcoded size
Icon(
    painter = painterResource(R.drawable.rounded_home),
    contentDescription = "Home",
    modifier = Modifier.size(36.dp), // ← NOT in the scale!
)

// ❌ NEVER — Icons.Default (= Filled)
Icon(
    imageVector = Icons.Default.Settings, // ← WRONG!
    contentDescription = "Settings",
    modifier = Modifier.size(WiomIcon.MD),
)

// ❌ NEVER — Icons.Filled
Icon(
    imageVector = Icons.Filled.Favorite, // ← WRONG!
    contentDescription = "Favorite",
    modifier = Modifier.size(WiomIcon.MD),
)

// ❌ NEVER — Icons.Outlined
Icon(
    imageVector = Icons.Outlined.Settings, // ← WRONG!
    contentDescription = "Settings",
    modifier = Modifier.size(WiomIcon.MD),
)

// ❌ NEVER — interactive icon without touch target
Icon(
    painter = painterResource(R.drawable.rounded_close),
    contentDescription = "Close",
    modifier = Modifier
        .size(16.dp)
        .clickable { }, // ← no touch target padding!
)
```

## Icon Color Rules

| State | Color Token | When |
|-------|------------|------|
| Default | `onSurface` | Primary icons on light backgrounds |
| Secondary | `onSurfaceVariant` | Muted/supporting icons, unselected nav |
| Selected / active | `primary` | Selected nav, active toggles |
| Disabled | `onSurface` at 38% opacity | Disabled interactive icons |
| Inverse | `onPrimary` or `inverseOnSurface` | Icons on colored backgrounds |
| Success | `success` semantic token | Success status icons (filled) |
| Warning | `warning` semantic token | Warning status icons (filled) |
| Error | `error` | Error status icons (filled) |
| Brand | `Color.Unspecified` | Wiom brand icons — no tinting |
| Partner | `Color.Unspecified` | Partner logos — no tinting |

**Never hardcode** values like `Color(0xFF333333)` on icons.

## Accessibility Rules

| Rule | Implementation |
|------|---------------|
| Interactive icons | `contentDescription` is **REQUIRED** — describe the action: "Search", not "Magnifying glass" |
| Decorative icons | `contentDescription = null` — hides from screen readers |
| Empty string | **NEVER** use `contentDescription = ""` — use `null` instead |
| Status icons | Must be paired with text or color — icon alone must not carry critical meaning |
| Disabled icons | Must still meet contrast minimums |
| Touch targets | Minimum 48dp for standard (icon.md), 40dp for compact (icon.xs, icon.sm) |
| Contrast | Meaningful icons must meet 3:1 contrast ratio against their background (WCAG). This is enforced by the semantic color tokens — do not override them with custom colors. |

## Rules — ALWAYS Follow These

### 1. Only use approved size tokens
Never hardcode icon sizes. Every icon MUST use `WiomIcon.XS`, `WiomIcon.SM`, `WiomIcon.MD`, or `WiomIcon.LG`. Sizes 12, 18, 28, 32, 36, 40, 56, 64dp are all wrong.

### 2. Material Symbols Rounded is the only source
Use `painterResource(R.drawable.rounded_*)`. Never use `Icons.Default`, `Icons.Filled`, `Icons.Outlined`, `Icons.Sharp`, or `Icons.TwoTone`.

### 3. Filled is default, outlined is only for toggle states
All single-state icons are filled. Outlined is used only for the inactive/unselected state of interactive toggles (unselected nav tab, inactive bookmark). If it doesn't toggle — it's filled.

### 4. Glyph ≠ container ≠ touch target
Set glyph size via WiomIcon token. WiomIconButton handles container and touch target. Don't manually size tap areas.

### 5. icon.xs (16dp) is restricted
Only for inline text indicators, input trailing icons, and status dots. Never for standalone tappable actions. Minimum for actions is 20dp (icon.sm).

### 6. Icons must not carry critical meaning alone
Status icons must be paired with text or color. Interactive icons need contentDescription. Decorative icons use contentDescription = null. Meaningful icons must meet 3:1 contrast ratio (WCAG).

### 7. Custom icons need design approval
Brand: `ic_wiom_*`. Partner: `ic_partner_*`. All must be 4dp multiples.

### 8. Color follows semantic tokens
Use `onSurface`, `onSurfaceVariant`, `primary`, `error`, etc. Never hardcode hex colors. Brand and partner icons use `Color.Unspecified`.

### 9. Never create custom icons — ask for drawables
Do not generate, draw, or create SVG/vector icons. Always use Material Symbols Rounded. If the needed icon doesn't exist in Material Symbols, ask the user to provide the drawable. Use a placeholder with a TODO comment until received.
